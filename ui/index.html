记忆是怎么组织的？

记忆版本 → 索引 → 主题分组 → Markdown 条目 → 事实与出处。

索引按领域列出主题和一句摘要。每个主题有独立条目，记录事实、日期和会话出处，并链接到相关主题。领域分组写在索引里，条目集中存放。

这沿用了 Cookbook 的 Wiki 结构。Harness 通过只读工具按需读取索引和条目。可在「配置与版本」切换整份记忆的版本。
